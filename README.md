# Major-project
self balancing robot
Designed and built a self-balancing robot from scratch using Arduino Nano, MPU-6050 sensor, L298N motor driver, and DC motors. Programmed a PID controller in C++ to process real-time tilt data and adjust motor speeds every 10 milliseconds to maintain upright balance. Tuned Kp, Ki, Kd values manually through trial-and-error testing until the robot stood stable without falling. Connected all components on a lightweight sun board chassis using soldering and jumper wires. Calibrated the gyroscope at startup for accurate angle reading. Achieved autonomous balancing, forward/backward movement, and recovery from light pushes. This project strengthened my skills in embedded systems, sensor fusion, control logic, circuit wiring, and real-time debugging.
